# College EsportsX

Official website for **College EsportsX**, host of the College Esports Expo and a strategic advisory platform focused on the collegiate esports marketplace.

## Hostinger deployment

This is a static website with no build step.

1. Connect this GitHub repository to Hostinger Git deployment, or clone it into the site's `public_html` directory.
2. Use the repository root as the publish source.
3. No build command is required.
4. Confirm `index.html` is deployed at the root of the public web directory.

## Structure

- `index.html` — production website
- `assets/` — optimized College EsportsX photography assets

## Positioning

College EsportsX focuses on collegiate esports strategy, education, ecosystem development, institutional advisory, partnerships, and the College Esports Expo (CEX).
